# HowRead Pro（华为应用市场渠道）权限用途说明

> **用途**：AGC 提审时"权限申报/敏感权限说明"的逐项填写底稿，以及审核被问询时的答复素材。
> **数据来源**：`HowRead-Huawei-v1.3.13-arm64.apk`（release）实际合并清单，逐项经 manifest-merger
> blame 报告归源（复核方法见文末附录），非凭文档推测。共 24 项 uses-permission（含广告 SDK
> 注入的 1 项应用级自定义权限；2026-09-20 起 AD_ID 已移除）。
> 最后更新：2026-09-20（对应 v1.3.13/7313 构建）。

## 一、需要重点申报的权限（AGC 后台"敏感权限"逐项填写）

### 1. 所有文件访问权限
- **权限**：`android.permission.MANAGE_EXTERNAL_STORAGE`（+ 旧版存储 `WRITE_EXTERNAL_STORAGE`、`READ_EXTERNAL_STORAGE`）
- **声明来源**：应用自身清单（`app/src/main/AndroidManifest.xml:9-10`）
- **用途**：这是一款**本地电子书阅读器**。用户书籍可能存放在设备任意目录（下载、文档、网盘同步目录等），Android 11+ 的分区存储无法覆盖任意外部路径，因此需要"所有文件访问"来**扫描并列出用户指定文件夹中的书籍文件、读取并渲染这些文件**。旧版存储权限用于 Android 10 及以下相同目的。
- **触发时机**：首次启动与用户主动修改"书籍目录"设置时执行目录扫描；打开书籍时读取该文件。应用**不写入、不上传**用户的任何文档。
- **审核答复措辞（可直接粘贴）**：
  > 本应用为本地电子书阅读器，"所有文件访问"权限仅用于扫描用户指定文件夹中的电子书文件并读取渲染（支持 PDF/EPUB/MOBI 等 20 余种格式）。书籍文件仅在本机处理，不上传服务器。用户也可在应用内选择只授权特定目录。

### 2. 前台服务（媒体播放类型）
- **权限**：`android.permission.FOREGROUND_SERVICE`、`android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK`
- **声明来源**：应用自身清单（main:11-12）
- **用途**：**TTS 朗读**功能——屏幕关闭或切换到其他应用时，朗读服务需以前台服务（mediaPlayback 类型）持续运行，并在通知栏提供 暂停/停止/上下句 控制项。
- **审核答复措辞**：
  > 前台服务（mediaPlayback 类型）仅用于 TTS 语音朗读电子书：熄屏或离 开应用后持续朗读并显示带控制按钮的通知栏。这是用户主动触发的功能，非后台保活。

### 3. 通知权限
- **权限**：`android.permission.POST_NOTIFICATIONS`
- **声明来源**：应用自身清单（main:20）
- **用途**：TTS 朗读时的**通知栏控制面板**（播放/暂停/停止）。
- **审核答复措辞**：
  > 仅用于显示 TTS 朗读的控制通知（暂停/停止），不发送营销或推广通知。

### 4. 生物识别
- **权限**：`android.permission.USE_BIOMETRIC`
- **声明来源**：应用自身清单（main:19）
- **用途**：用户为书籍/应用设置密码后，可用**指纹/面容解锁**代替输入密码（`PasswordDialog`）。
- **审核答复措辞**：
  > 仅在用户主动为应用或书籍设置密码后，提供指纹/面容等生物特征解锁选项，生物信息由系统 BiometricPrompt 处理，应用不收集。

### 5. 开机广播
- **权限**：`android.permission.RECEIVE_BOOT_COMPLETED`
- **声明来源**：**AndroidX WorkManager（androidx.work:work-runtime:2.11.2）清单自动声明**，应用未自定义开机接收器
- **用途**：WorkManager 在设备重启后**恢复未完成的后台任务**（如中断的书库扫描/文件整理任务）。
- **审核答复措辞**：
  > 由 Android 官方任务调度组件 WorkManager 声明，用于设备重启后恢复未完成的应用内任务（如书库扫描），不涉及开机自启动业务推广。

### 6. 查询所有应用包（QUERY_ALL_PACKAGES）——重点
- **权限**：`android.permission.QUERY_ALL_PACKAGES`
- **声明来源**：**华为广告 SDK（com.huawei.hms:ads-base-prime:13.4.90.302）清单自动声明**——本应用三渠道对比（fdroid/pro/huawei 合并清单差分）证实该权限仅存在于华为渠道包，由 ads-base-prime 注入；**应用自身代码没有声明它，也不遍历安装应用列表**。
- **应用自身与包查询相关的能力**：仅 `DictsHelper.resolveInfosList()` 用 `queryIntentActivities(MATCH_DEFAULT_ONLY)` 查询**能打开某文件的应用**（系统"打开方式"选择器配套），不需要该权限即可工作。
- **审核答复措辞（可直接粘贴）**：
  > 该权限由华为 Petal Ads SDK（ads-base-prime）在其 SDK 清单中自动声明，用于广告投放过程中的系统兼容性判断；本应用代码自身未声明、也未调用遍历已安装应用列表的接口。应用自身的包查询仅限系统"打开方式"选择器所需的 intent 查询。
- **回退方案**（若审核驳回）：在华为渠道 manifest 中以 `tools:node="remove"` 移除该权限（华为渠道 manifest 已有同类先例：AGConnectInitializeProvider），移除后需真机复验广告填充。

## 三、华为广告 SDK 自动声明的设备/系统权限（无需应用逐条解释，统一答复）

以下权限**全部由华为 Petal Ads SDK（ads-core-prime / ads-base-prime / ads-splash-prime，3.4.90.302）清单自动注入**（blame 报告逐条归源证实），应用代码未直接调用：

| `com.huawei.permission.sec.MDM.v2` / `com.hihonor.permission.sec.MDM.v2` | ads-core-prime | 广告反作弊（华为/荣耀设备安全管理接口） |
| `com.huawei.permission.sec.ACCESS_UDID` / `com.hihonor.…UDID` | ads-core-prime | 广告设备标识（OUID/UDID，受华为隐私管控） |

> 以上权限均由华为 Petal Ads SDK 清单自动声明，是华为官方广告组件的标准依赖项，用于广告投放、反作弊与设备适配；本应用业务代码不直接调用。华为广告 SDK 的个人信息处理遵循《华为广告隐私声明》（应用内隐私政策已披露）。

## 五、附录：如何复核本说明

```bash
# 1. 导出 huawei 包实际权限（release, arm64）
aapt2 dump badging app/build/outputs/apk/huawei/release/HowRead-Huawei-v*-arm64.apk | grep uses-permission

# 2. 逐项归源（manifest-merger blame 报告：每行注明声明文件与行号）
cat app/build/intermediates/manifest_merge_blame_file/huaweiRelease/*/manifest-merger-blame-huawei-release-report.txt

# 3. 三渠道差分（确认某权限来自哪个渠道依赖）
aapt2 dump badging app/build/outputs/apk/<fdroid|pro|huawei>/release/HowRead-*.apk | grep -c '<权限名>'
```

对照的构建版本：v1.3.13（appCodeNumber 7313），2026-09-19/20 构建。升级版本或调整依赖后请重跑附录命令同步本说明。
