## 用例禁用机制（2026-09-13 新增）

`config/cases.yaml` 的 `case_meta.<用例ID>` 支持 `enabled: false`，`run_all.py` 执行前自动过滤被禁用用例并打印日志。当前禁用清单：
- **FN-25 OPDS 浏览**：Gutenberg 预置源依赖外网，真机常不可达；待内网 OPDS 源搭建后重新启用。

## 轮次前置：APK 版本一致性 + 状态重置（2026-09-13 检视新增）

`run_all.py` 的 `prepare_device`（worker 内、用例执行前）保证**设备上的包 == 待测 APK**：
- 默认：APK 文件名版本号 ≠ 设备 `versionName` 时自动升级安装 + 授权 + Pro 解锁；一致则跳过（快速）。
- `--reset`：`pm clear` 清数据 + 重装 + 授权 + **Pro 解锁自动写入** + 重推基准书——**全量回归金标准**，从出厂态起跑，排除上一轮残留状态（书签/收藏/服务器条目/阅读进度/偏好）干扰。代价：三协议凭据（WebDAV/SMB/SFTP）需一次性重新入库，网络用例首轮多约 3 分钟。
- `--no-install`：跳过安装仅告警——单用例快速调试用。

**Pro 解锁**（`ensure_pro_unlocked`，仅 pro 包）：pm clear 后 `iapProUnlocked` 键永不落盘（SDK30 权限预授时应用首启不触发 `AppSP.save()`），须预写 `shared_prefs/AppTemp.xml`（base64 写入，见 PITFALLS 24）——否则 FN-22/23/24/26~30/43/44 全部被 Pro 锁挡住。

**用例级状态自洽**（不依赖全局重置）：每个用例入口 `_ensure_home`（唤醒解锁 + 白名单 + 冷启到主界面 + 系统弹窗清理 + 残留阅读器 back 兜底）；模式相关用例热态开书（`_open_reader_warm`，规避冷启丢内存态偏好）；网络用例 `_ensure_server` 幂等复用服务器条目、用后删除自建条目；设置类用例改完还原。

## 关键真机结论（2026-09-13，修复/绕行的依据）

| 主题 | 结论（代码+真机证据） |
|------|----------------------|
| 跳页/TTS 入口 | 底栏「前往页面」(`R.id.thumbnail`)与「文字转语音」(`R.id.textToSpeach`)仅在水平(Book)模式由 `HorizontalViewActivity.restoreFooterControls()` 点亮；垂直滚动模式恒 GONE。`AppSP.readingMode` 经偏好「单机行为→左右翻页」切换后**只写内存**（AppTemp.xml 落盘不含 force-stop），故切换后必须热态开书（`_open_reader_warm`），冷启即丢 |
| 应用侧建议 | 垂直模式如需跳页/TTS 入口：`DocumentWrapperUI.java:2100`（showOutline 内）补一行 `findViewById(R.id.thumbnail).setVisibility(VISIBLE)`（listener 已在 :1294 挂好）；TTS 同理 |
| 标签入口 | 长按书行（defaultLongClick=书菜单 ShareDialog）→[文件信息]→`R.id.addTags`；勾选[应用]后 `Tags2.setTags` 只写 app-Tags2.json，信息对话框标签行读 AppDB 缓存（updateTagsDB 未触发前不回显）——断言以落盘文件为准 |
| 书库行定位 | 书架/封面视图的书名是封面位图无文本节点，textContains 命中的是搜索框自己——必须切列表/简表视图（`_ensure_list_row`）并用行右 ⋮(`R.id.itemMenu`) 操作 |
| SMB/SFTP 凭据 | 密码经 AndroidKeyStore AES/GCM 加密存 SharedPreferences(`webdav.xml`,键 remote://<id>)，文件无法伪造；UI 添加对话框中**触碰密码框必触发 MIUI 密码保险箱打崩 a11y**——密码阶段全程 adb（坐标从 u2 存活时的 dump 预取），跳过测试连接直接点添加（正键不依赖测试连接） |
| **远程打开管线回归（已修复，2026-09-13）** | 曾 FAIL：点击远程书后，应用发出 `GET /book.pdf|epub → 206`（尾部预读成功）**之后管线静默死亡**（无后续 probe/打开请求、无提示、无崩溃，页面退回列表）；epub/pdf 均复现、重启手机无效；服务器侧完全正常（PROPFIND 207/GET 206）。**同一 APK 昨天(09-12 23:42)FN-30 通过**——间歇性应用缺陷，由其它任务定位修复。**v1.3.2 构建 MI9 复跑验证通过**：FN-30 连跑 3 次全过（54.3s / 55.1s / 135.0s，第 3 次首试 u2 JSON-RPC 瞬断、自动重试通过——框架已知坑非应用问题），FN-46 89.7s 一次通过（断网→重开→翻页→恢复网络全链路） |
| SFTP startDir | 家目录相对语义（RemoteServer.startDir），填绝对路径会解析成 home 下嵌套路径导致浏览为空 |
| MIUI 长跑坑 | ①长时间运行会熄屏，熄屏期间 u2/点击/截图全废——每个用例开头与冷启动后必须 `wake_unlock`；②u2 dump/click 偶发 JSON-RPC 瞬态崩溃，数秒自愈，关键路径需重试 |
| 阅读偏好弹窗 | DragingPopup 容器可拖拽（swipe 会拖走弹窗而非滚动）；分区（可视选项/排版选项/状态栏/控制选项）靠点分区头展开；本 fork 弹窗无[行距]行（line_spacing 字符串无代码引用） |
| 音量键/分区 tap（FN-49/51） | ①音量键/分区 tap 对 **PDF** 可靠，**epub 水平模式 pagesCountIndicator 不出现**（页码读不到，页码断言类用例勿用 epub）；②小屏 `isReverseKeys=true` → **VOLUME_UP=回翻、VOLUME_DOWN=下翻**（与 AppState NEXT_KEYS 常量表相反）；③书首/末页单向操作不动，先前进到第 3 页起测；④intent 直开时书名关键词检索会误中同名书（big25 PDF 与 TXT 基准书都叫 Bench25），精确控样本必须用 `open_book_via_intent` 文件路径直开 |
| 中央 tap / 双击 UI 切换 | 水平(Book)模式的中央 tap 与默认双击动作(SHOW_HIDE_UI)只切换**顶栏**（页脚页码常驻），垂直模式才整块切换——断言用「顶栏(imageToolbar)+页脚」组合状态比较；`_reader_show_toolbar` 可见判断必须计入 pagesCountIndicator，否则会把已显示界面当隐藏、点中心反而藏掉 |
| **阅读器静默退出（疑似应用侧缺陷，与远程打开回归同族）** | FN-49/51 调试期间多次观测：阅读器打开/翻页后 **app 无声退到桌面**（wm_finish_activity=app-request 后任务清空，两次进程直接死亡 proc died；crash 缓冲区无记录、无提示）。间歇性、复现率不稳定（探针连续 15 次操作可全通过，框架连跑时频发）——用例内做存活校验+重开书重试（`_reader_alive`）兜底。建议随 FN-30/46 一并用 IS_LOG 构建定位 |
