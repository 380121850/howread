# 贡献者

HowReadPro（好好读Pro）是一款开源电子书阅读软件，由 [Librera Reader](https://github.com/foobnix/LibreraReader) fork 而来。感谢 Librera 上游社区多年来对开源阅读生态的贡献。

## Librera 项目早期贡献者

- **Максим Біляк（Max Bilyak）** — 视觉障碍适配专家，为视障用户提供了大量改进建议与测试支持
- **Горшков Сергій（Sergei Gorshkov）** — 核心测试人员与客户支持，负责版本质量把关与用户反馈收集

## HowReadPro 社区

HowReadPro 继续秉承开源、无锁定的理念，欢迎任何形式的贡献：

- **文档改进** — 翻译、错别字修正、FAQ 补充
- **代码提交** — Bug 修复、新功能开发、性能优化
- **问题反馈** — 通过 [GitHub Issues](https://github.com/380121850/howread/issues) 报告问题或提出建议

感谢每一位为 HowReadPro 和 Librera 项目付出时间与精力的社区成员。
